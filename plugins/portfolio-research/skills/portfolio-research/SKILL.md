# 1회차 — 데스크 리서치

산출물은 `01_research/` 에 저장한다.

## Phase 1 — 스코핑 (수업 중, 15분)

리서치를 바로 실행하지 않는다. **먼저 5개를 묻는다.** 답이 부실하면 리서치 결과 전체가 부실해진다.

1. 관심 영역이 무엇인가? (한 문장)
2. 누구를 위한 서비스인가? (연령·상황까지)
3. 이번 조사에서 **가장 알고 싶은 것 한 가지**는? (여러 개면 하나로 좁히게 한다)
4. 떠오르는 유사 서비스 2~3개는?
5. 국내만? 해외 포함?

답을 `01_research/scope.md` 에 저장하고, 학생에게 **읽어 주고 확인받는다.**

## Phase 2 — 실행 (과제, 수업 시간에 하지 않는다)

> 학생에게 반드시 알린다: "리서치 실행은 시간이 오래 걸립니다. 수업 중에 돌리지 말고, 집에서 실행한 뒤 다음 주에 결과를 가져오세요."

`insane-research` 플러그인이 설치돼 있으면 Phase 1 결과를 구조화된 질문으로 변환해 넘긴다. 원본 리포트는 `01_research/raw/` 에 **그대로 보존한다.** 요약본만 남기면 나중에 근거를 못 찾는다.

**폴백 (`--lite`)** — 시간이 없거나 실행이 실패한 학생용. 웹 검색만으로 5~10분 안에 끝낸다. 대신 출처를 **최소 5개** 확보하고, 품질이 낮음을 결과물 상단에 명시한다.
```
> ⚠️ 이 리서치는 간이 모드로 수행됐습니다. 포트폴리오에 쓰기 전 출처를 직접 확인하세요.
```

## Phase 3 — 포트폴리오 변환 (여기가 이 스킬의 핵심)

리서치 리포트는 포트폴리오 재료가 아니다. 세 파일로 압축한다.

**`market-summary.md`** — A4 한 장 분량. 시장 규모·성장률·주요 변화 중 **숫자 3개**와 각각의 출처 URL. 숫자를 못 찾으면 "찾지 못함"이라고 쓴다. 지어내지 않는다. (루브릭 F-1: 근거 없는 숫자 -5점)

**`competitor-matrix.md`** — 유사 서비스 4~6개 × 비교축 5개 표. 비교축은 Phase 1의 3번 질문에서 도출한다. 각 셀에 근거(화면·기능·가격 정책 등)와 확인한 URL.

**`opportunities.md`** — 기회 영역 **정확히 3개.** 각각:
- 무엇이 비어 있는가 (한 문장)
- 왜 비어 있다고 보는가 (비교표의 어느 칸에서 나왔는지 지목)
- 이걸 노릴 때 예상되는 어려움

3개는 서로 충분히 달라야 한다. 비슷하면 학생이 2회차에 고를 게 없어진다.

## 마무리

- `## 확인 필요` 섹션에 검증 못 한 것을 모은다.
- `decisions.md`에 "조사 범위를 이렇게 좁혔다"를 기록한다.
- 자가 점검 3문항:
  - [ ] 출처 URL이 3개 이상 실제로 열리나요?
  - [ ] 경쟁 서비스를 직접 써 보거나 화면을 봤나요?
  - [ ] 기회 영역 3개가 서로 다른 이야기인가요?

## 공통 규칙 (이 스킬에도 그대로 적용)

1. **입력 게이트** — 필요한 정보가 없으면 질문부터 한다. 추측해서 진행하지 않는다.
2. **근거 강제** — 모든 주장에 근거를 붙인다. 리서치는 출처 URL, 평가는 화면 위치, 채점은 원문 인용.
3. **불확실 분리** — 확인 못 한 것은 결과물 맨 뒤 `## 확인 필요` 에 따로 모은다. 본문에 섞지 않는다.
4. **분량 상한** — 발견 항목은 Top 5, 액션은 3개까지.
5. **학생이 결정한다** — AI는 선택지를 좁혀 주고, 고르는 것은 학생이다. AI가 대신 고르면 채점표 F-3(AI 결과물을 설명할 수 없음, -3점)에 그대로 걸린다.
6. **판단 기록** — 학생이 무언가를 고를 때마다 `decisions.md` 에 한 항목을 추가한다.

## 작업 폴더

산출물은 프로젝트 폴더 아래에 쌓인다. 없으면 프로젝트 이름을 묻고 만든다.

```
PORTFOLIO/{프로젝트명}/
  01_research/  02_problem/  03_design/  04_heuristic/  05_review/
  decisions.md  progress.md
```

처음 만들 때 학생에게 알린다: "앞으로 매주 이 폴더에 결과가 쌓입니다. **항상 같은 폴더를 열어야** 이어집니다."

`decisions.md` 기록 형식:
```
## [N회차] {무엇을 골랐는가}
- AI가 제안한 것: {…}
- 내가 고른 것: {…}
- 이유: {한 문장}
- 포기한 것: {있으면}
```

## 끝낼 때

1. 산출 파일을 해당 폴더에 저장한다.
2. `decisions.md` 와 `progress.md` 를 갱신한다.
3. 아래 자가 점검을 출력한다.
4. 다음 단계 명령을 한 줄로 안내한다.
