# 남들은 뭘 만들었나 찾아보기

관심 분야를 조사해서 **바로 쓸 수 있는 파일 세 개**로 만들어 준다.

## 1단계 — 무엇을 조사할지 정한다 (제일 중요)

바로 조사하지 않는다. **먼저 다섯 가지를 묻는다.** 여기가 부실하면 조사 결과 전체가 부실해진다.

1. 어떤 분야에 관심이 있나요?
2. 누가 쓸 서비스인가요? (나이와 상황까지)
3. 이번 조사에서 **제일 알고 싶은 것 한 가지**는 무엇인가요?
4. 떠오르는 비슷한 서비스가 두세 개 있나요?
5. 한국만 볼까요, 해외도 볼까요?

3번에 여러 개를 답하면 하나로 좁히게 한다. 여러 개를 알아보려 하면 답이 흐려진다.

답을 정리해 읽어 주고 **맞는지 확인받는다.**

## 2단계 — 조사한다

`insane-research` 플러그인이 설치돼 있으면 1단계 답을 질문으로 바꿔 넘긴다. 원본 리포트는 `research/raw/` 에 **그대로 남긴다.** 요약만 남기면 나중에 근거를 찾을 수 없다.

설치돼 있지 않거나 학생이 "간단하게"라고 하면 웹 검색만으로 진행한다. 대신 출처를 **최소 다섯 개** 확보하고, 결과 맨 위에 적는다.

> ⚠️ 이 조사는 간단 모드로 했습니다. 포트폴리오에 넣기 전에 출처를 직접 확인하세요.

**시간이 오래 걸린다는 것을 미리 알린다.** 수업 중이라면 1단계까지만 하고 실행은 나중에 하라고 안내한다.

## 3단계 — 쓸 수 있는 형태로 바꾼다

조사 리포트는 그대로 쓸 수 없다. 세 파일로 줄인다.

**`research/market-summary.md`** — A4 한 장. 시장 크기·성장·주요 변화 중 **숫자 세 개**와 각각의 출처 링크. 못 찾은 숫자는 "찾지 못함"이라고 쓴다. **지어내지 않는다.**

**`research/competitor-matrix.md`** — 비슷한 서비스 네다섯 개 × 비교 기준 다섯 개 표. 비교 기준은 1단계 3번 답에서 뽑는다. 각 칸에 근거와 확인한 링크를 붙인다.

**`research/opportunities.md`** — 아직 비어 있는 자리 **정확히 세 개.** 각각:
- 무엇이 비어 있는가 (한 문장)
- 왜 비어 있다고 보는가 (비교표의 어느 칸에서 나왔는지)
- 여기를 노리면 무엇이 어려울까

셋은 서로 충분히 달라야 한다. 비슷하면 고를 이유가 없어진다.

## 지키는 것

1. **모르면 묻는다** — 필요한 정보가 없으면 질문부터 한다. 추측해서 진행하지 않는다.
2. **근거를 붙인다** — 모든 주장에 근거를 붙인다. 숫자에는 출처, 지적에는 위치.
3. **확실하지 않은 건 따로 모은다** — 확인 못 한 것은 맨 뒤 `## 확인 필요` 에 모은다. 본문에 섞지 않는다.
4. **길게 쓰지 않는다** — 항목은 5개, 고칠 것은 3개까지.
5. **고르는 건 학생이다** — 선택지를 좁혀 주되 결정은 학생이 한다. AI가 대신 고르면, 나중에 "왜 이렇게 했나요"에 답할 수 없게 된다.
6. **쉬운 말로 말한다** — 어려운 용어를 쓸 때는 괄호로 뜻을 함께 적는다.

결과는 학생이 지금 열어 둔 폴더에 저장한다. 다른 스킬이나 이전 결과물을 필요로 하지 않는다.

## 끝낼 때

`## 확인 필요` 에 검증 못 한 것을 모으고, 아래를 출력한다.

```
넘어가기 전에 확인하세요
□ 출처 링크 세 개를 눌러서 실제로 열리나요?
□ 비슷한 서비스를 직접 켜서 봤나요?
□ 비어 있는 자리 세 개가 서로 다른 이야기인가요?
```
