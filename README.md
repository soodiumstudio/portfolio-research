# portfolio-research

80회차 UX/UI 포트폴리오 커리큘럼 — **1회차** 단계 스킬.

## 설치

```bash
/plugin marketplace add https://github.com/soodiumstudio/portfolio-research.git
```

```bash
/plugin install portfolio-research
```

## 사용

```bash
/portfolio-research
```

## 전체 순서에서 이 스킬의 자리

| 회차 | 명령 | 산출 폴더 |
|---|---|---|
| 1 | `/portfolio-research` | `01_research/` |
| 2 | `/portfolio-problem` | `02_problem/` |
| 3~4 | `/portfolio-design` | `03_design/` |
| 5 | `/portfolio-heuristic` | `04_heuristic/` |
| 6 | `/portfolio-review` | `05_review/` |

각 스킬은 앞 단계 폴더를 읽습니다. 앞 단계 산출물이 없으면 무엇이 없는지 알려주고 멈춥니다.
결과는 모두 `PORTFOLIO/{프로젝트명}/` 아래에 쌓입니다 — **매주 같은 폴더를 열어야 이어집니다.**
